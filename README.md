# わりわりアイランド

あまりのないわり算と、あまりのあるわり算をゲーム感覚で練習できる小学生向けの算数Web教材です。

## 公開ページ

[わりわりアイランドを開く](https://tt-sensei.github.io/warizanland/)

## 学べること

- わり算の基本的な計算
- あまりのないわり算
- あまりのあるわり算
- わる数とあまりの関係
- 正確に答える力と、素早く計算する力

## 主な機能

- 「あまりなし」「あまりあり」の2モード
- 60秒・90秒の制限時間
- 数字キーパッドによる入力
- 連続正解コンボ
- コインとハイスコアの記録
- 結果画面からの再挑戦
